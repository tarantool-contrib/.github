# Getting help

Modules in tarantool-contrib are community-maintained and come with **no
commercial support and no guaranteed response time**. Maintainers help on a
best-effort basis.

- **Bug in a module** — open an issue in that module's repository; see
  [CONTRIBUTING.md](CONTRIBUTING.md) for what to include.
- **Question about using a module** — open an issue in that module's repository
  (or a discussion, if the repository has Discussions enabled).
- **Question about Tarantool itself** — ask in the
  Tarantool community chats on Telegram:
  [English](https://t.me/tarantool), [Russian](https://t.me/tarantoolru).
- **Security issue** — follow [SECURITY.md](SECURITY.md); never report it publicly.

The Tarantool team does not provide support for modules in this organization.
Please do not report module problems to the official Tarantool issue tracker.

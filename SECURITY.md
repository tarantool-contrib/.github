# Security policy

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately through GitHub instead:

1. Open the affected repository.
2. Go to the **Security** tab and press **Report a vulnerability**.

The report is visible only to the repository's maintainers and the organization
owners. Include the affected version, a description of the impact, and a
reproducer if you have one.

If the vulnerability is in Tarantool itself rather than in a module, report it
to the Tarantool project instead.

## What to expect

Modules in this organization are maintained by volunteers, so there is no
guaranteed response time. We aim to:

- acknowledge a report within 7 days;
- agree on a fix and a disclosure date with the reporter;
- publish a fixed release and a GitHub security advisory crediting the reporter,
  unless they prefer to stay anonymous.

If a module has no active maintainer, the organization owners handle the report,
and may archive the module when a fix is not feasible.

## Supported versions

Unless a module's own `SECURITY.md` says otherwise, only its latest release
receives security fixes.
